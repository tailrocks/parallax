# Plan 095 Oxc dependency review

Review date: 2026-07-12

Parallax uses one Rust-native TypeScript analysis implementation:

| Crate | Version | Source | License | Purpose |
| --- | --- | --- | --- | --- |
| `oxc_parser` | 0.139.0 | `oxc-project/oxc` | MIT | JS/JSX/TS/TSX AST and module records |
| `oxc_ast` | 0.139.0 | `oxc-project/oxc` | MIT | typed syntax nodes and spans |
| `oxc_semantic` | 0.139.0 | `oxc-project/oxc` | MIT | scopes, syntax checks, and complete node traversal |
| `oxc_resolver` | 11.24.2 | `oxc-project/oxc-resolver` | MIT | tsconfig aliases, extension/index and package-exports resolution |

The allocator and span crates are pinned to the same 0.139.0 Oxc family. All
selected versions support the repository's Rust 1.97 toolchain. The provider
fails closed on parser, semantic, resolution, and nonliteral dynamic-import
errors. It is the sole authoritative UI import graph; no live Oxlint dependency
or second architecture graph is introduced by Plan 095.

The tool-neutral downstream corpus is
`crates/parallax-xtask/fixtures/typescript-import-parity.json`. Its inventory is
asserted by xtask tests and is intended for later supplemental-tool parity in
Plans 100, 129, 131, and 132.
