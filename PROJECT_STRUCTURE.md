# Project Structure

This file is the stable top-level ownership map. Detailed research navigation
lives in [the research index](docs/research/README.md), and Rust crate/module
ownership lives in the [Rust workspace map](docs/research/architecture/rust-workspace-map.md).

## Product shape

Parallax ships a Rust workspace and a TanStack Start UI. The mandatory runtime
stack is GreptimeDB for telemetry plus Turso for metadata. Research, decisions,
and active implementation plans remain plain Markdown.

## Root contracts

| Path | Ownership |
| --- | --- |

## Generated and checked surfaces

- `crates/*/facade.toml` is syntax-derived and drift-checked.
- `ui/src/routeTree.gen.ts` is generated by TanStack tooling.
- Semantic-convention outputs are generated from
  `telemetry/semconv/contract.yaml` and checked by the pinned Weaver registry
  plus negative fixtures under `telemetry/semconv/fixtures/`.
- `bun.lock` is the only JavaScript lockfile.
- Build outputs, benchmark datasets, and vendored comparison services remain
  untracked.

## Update rule

Update this file only when top-level ownership changes. Update the workspace map
when crate ownership or tiers change, and the research index when research
navigation changes.
