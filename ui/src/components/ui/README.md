# UI primitive conventions

- Use Tabler icons only in primitives.
- Prefer `*Filled` variants when one exists.
- Default glyph size is `size-3.5`.
- Use `size-3` for dense contexts, `size-4` for menus and inputs, and `size-4.5` for sidebar icons.
- Fall back to an outline icon only when Tabler has no filled export.
