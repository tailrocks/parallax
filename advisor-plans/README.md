### Findings considered and rejected / deferred (2026-07-10 audit)

Recorded so they are not re-audited; "deferred" items may be planned later.

- **ID newtypes (TraceId/SpanId/RunId/Fingerprint)**: real smell (~97 bare
  `String` sites), wide mechanical blast radius; deferred — revisit as a
  spike on `trace_id` only if a confusion bug actually appears.
- **Typed `StoreError` enum replacing anyhow-at-the-boundary** (119×
  `.map_err(field_err)` collapses everything to strings): real architecture
  gap; deferred until after 078 makes it reviewable per domain.
- **`traces.$traceId.tsx` split (1,500 lines, 29 components)**: fold into the
  next feature that touches trace view; not standalone-planned.
- **Single ingest worker (no pipelining/pool)**: acceptable for the local
  profile today; revisit with server profiles (V2). 076 reduces per-item cost
  first.
- **GreptimeDB read-path row clones + `SELECT *` on `select_spans`**:
  entangled with schema auto-widening; bounded by MAX_ROWS=500; deferred.
- **`fingerprint::normalize_message` 7 regex passes**: bounded to error
  events; measure before optimizing; deferred.
- **UI metric-strip 5s full-window poll**: server-side cost fixed by 075's
  cache; delta-fetching deferred.
- **Route-level code splitting verification** (is TanStack auto-splitting
  active?): LOW-confidence investigate; check the build's chunk graph when
  next touching vite config.
- **CI check/clippy job merge**: redundant compile is real, but parallel
  wall-clock beats runner-minutes here; not worth doing (recorded choice).
- **Docs link-checker job**: all 174 sampled links resolve today; add lychee
  only if drift starts appearing.
- **Pre-commit hooks / .editorconfig**: optional DX; operator preference not
  known; deferred.
- **turso 0.6 pre-1.0 on the metadata path**: stack is operator-mandated
  (GreptimeDB+Turso, no substitutions); pin tightening to `=0.6.x` rejected
  (version policy says latest stable); the `update_with_open_statement_is_lost`
  characterization test in `metadata.rs:1029` documents a real turso
  lost-update hazard — keep the comment-guarded discipline, fix forward
  upstream if it bites.
- **`histogram_count_series` on memory adapter**: not audited for the same
  bug as greptime's (070); conformance suite (074) will surface any gap.
- **tower-http duplicate versions in the lock**: upstream (reqwest) —
  resolves itself; recorded to avoid re-flagging.
- **`shadcn` CLI-only usage / corner-shape pre-release dep**: handled in 079
  (move to devDeps); corner-shape kept (actively used in styles.css) — native
  CSS `corner-shape` migration is a cosmetic future.
- **Raw GraphQL/SSE surfaces are unredacted** (only `bundle` redacts): BY
  DESIGN for the human-owned local UI today, but it becomes a violation the
  moment any agent transport reads those endpoints — the boundary decision is
  restated in 072/083; revisit before MCP ships.
- **Bench compose stable pin v1.0.2 lags engine 1.1.2**: bench-only; bump on
  the next four-way benchmark run per the benchmark rule.
- **V2 auth tokens + `parallax context add`** (direction finding D-05): the
  smallest concrete V2 brick — `client.rs` already stubs the token field.
  Deliberately NOT planned: operator decides when V2 opens; write the ADR

- **Evidence pinning past TTL** (direction finding D-06): designed-but-unbuilt

## Findings considered and rejected (022-034 audit)

- **Split the 2181-line `crates/parallax-api/src/lib.rs`**: real tech debt, but
  a pure module re-org is not worth a standalone plan now — fold it in
  opportunistically when a feature plan (028-032) adds a resolver.
- **N+1 sub-resolvers on `runs`/`issues` list items** (no dataloader): real,
  but Juniper has no built-in dataloader and the fix is entangled with a
  batching-layer decision; the 500-row cap bounds the blast radius today.
- **`traces_search` unbounded whole-table aggregate**: real and worth fixing,
  but pre-existing and orthogonal to the brief; candidate for its own perf
  plan.
- **OTLP payload limits rely on framework defaults**: bounded already; pin
  explicitly someday, not plan-worthy now.
- **`Worker.seen_runs` grows unbounded**: slow leak on very long-lived
  servers; low severity, deferred.
- **Persisted occurrence idempotency for late span/log echoes**: valuable but
  schema-changing; 026 lands bounded in-batch dedup and defers a durable seen
  `(trace_id, span_id, fingerprint)` table.
- **`metric_point_count` stubbed to 0 / metric trend empty**: a documented V1
  gap, not a regression; deferred.
- **Stringly-typed UI GraphQL client** (no variables/codegen): real DX debt,
  but the manual escaper is safe today and a codegen migration is a large
  independent change; deferred.
- **Causal reconstruction** (typed nodes/edges + strength tiers): confirmed
  research-only, no code exists. Deliberately NOT planned — story (029) +
  evidence gaps (032) + ecosystem (031) deliver the near-term
  causal-navigation value without it.

## Verification baseline

UI (from `ui/`): `rtk bun run typecheck` / `lint` / `test` / `build` — all
must exit 0. Dev: `rtk bun run dev`. Rust (repo root):
`rtk cargo build --workspace`, `rtk cargo clippy --workspace --all-targets`
(zero warnings), `rtk cargo fmt --all`, `rtk cargo nextest run`. Manual checks
need `parallax serve` + traffic (the sibling telemetry playground repo). Git:
work on `main` (BRANCHING.md), Conventional Commits (COMMITS.md),
`git commit -s`.
