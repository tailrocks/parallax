# Security

This is a public Tailrocks Pte. Ltd. repository. Its source and public project
history are intentionally published under Apache-2.0; vulnerability reports,
secrets, customer data, and embargoed incident details are not public material.

Do not disclose vulnerabilities, secrets, customer data, private logs, or
embargoed incident details publicly before Tailrocks has coordinated a fix.

Report security concerns directly to the Tailrocks repository owner or through
the private channel provided to you by Tailrocks Pte. Ltd.

Public issues and pull requests are not vulnerability-reporting channels. If no
private reporting channel has been provided, contact the repository owner
privately before sharing technical details; this repository does not publish a
security address that has not been confirmed by the operator.
