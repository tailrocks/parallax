## Design-decision record (applies to all plans)

- Reference look is copied 1:1; Parallax keeps its own brand mark, nav structure, and the
  **collapsible sidebar** (`collapsible="icon"` + trigger + Cmd/Ctrl+B) — an intentional
  divergence from the reference (which ships no collapse).
- Elevation = `--custom-shadow*` tokens; borders only where the reference itself uses them
  (table row dividers, dashed empty states, dark-mode hairline idiom).
- Time range lives in the **URL** (zod `validateSearch`), not localStorage — divergence from
  the reference, justified by the agent-handoff product goal and `ui/AGENTS.md` rule 6.
- `font-mono` maps to Geist Mono (the reference's *intended* mono; its own wiring has a
  known drift).
- Icons: `@tabler/icons-react`, filled-first, sizes 3.5/3/4/4.5 per context.
- Old spec line "default theme as-is" (`docs/research/architecture/simple-ui-v2.md`) is
  superseded — plan 005 records the new decision in that doc without naming the reference.
